## ذخیرۂ الفاظ

| | |
| --- | --- |
| سَوِىَ (س) سِوَىً: برابر ہونا، درست ہونا | وَقَىَ (ض) وِقَايَةً: بچانا |
| (تفعيل): نوک پلک درست کرنا | (افتعال): بچنا، پرہیز کرنا |
| (افتعال): برابر ہونا | تَقْوَىٰ: اللہ کے ناراض ہونے کا خوف |
| اِسْتَوَىٰ عَلَى: کسی چیز پر متمکن ہونا، غالب آنا | عَذَىَ (س) عَذًى: تکلیف پہنچانا |
| اِسْتَوَىٰ إِلَى: متوجہ ہونا، قصد وارادہ کرنا | (افعال): تکلیف پہنچانا |
| وَفَىَ (ض) وَفَاءً: نذر یا وعدہ پورا کرنا | هَوَىَ (س) هُوًى: چاہنا، پسند کرنا |
| (افعال): وعدہ پورا کرنا | (ض): هُوِيًّا: تیزی سے نیچے اترنا |
| (تفعيل): حق پورا دینا | الْهَوَاءُ: فضا، ہوا |
| (تَفَعُّل): حق پورا لینا، موت دینا | الْهَوَى: خواہش، عشق |
| حَيِيَ (س) حَيَاةً: زندہ رہنا | لَوَىَ (ض) لَيًّا: رسی بٹنا، موڑنا |
| حَيَاءٌ: شرمانا، حیا کرنا | عَيِيَ (س) عَيًّا: کام سے تھک جانا، عاجز ہونا |
| (افعال): زندہ کرنا، زندگی دینا | لَحِقَ (س) لَحَقًّا: کسی سے جامِلنا |
| (تفعيل): درازی عمر کی دعا دینا، سلام کرنا | (افعال): کسی کو کسی سے ملا دینا |
| (استفعال): شرم کرنا، باز رہنا | |
| حَيَّ: متوجہ ہو، جلدی کرو | بَخُسَ (ف) بَخْسًا: گھٹنا |

## مشق نمبر 75 (الف)

مندرجہ ذیل مادّوں سے ان کے سامنے دیئے گئے ابواب میں اصلی اور تبدیل شدہ شکل میں صرف صغیر کریں:
1. وَقَىَ (ض): افتعال
2. وَفَىَ: افعال، تفعيل، تفَعُّل
3. سَوِىَ: تفعيل، افتعال
4. حَيِيَ (س): افعال، استفعال

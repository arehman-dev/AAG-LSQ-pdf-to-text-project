لسان القرآن

عربی میں ترجمہ کریں:

| | |
|---|---|
| | یقیناً اللہ ہی بخشنے والا رحم کرنے والا ہے |
| | یقیناً تو ہی تو بہ قبول کرنے والا رحم کرنے والا ہے |
| | یقیناً وہ ہی سننے والا جاننے والا ہے |
| | یقیناً وہ ہی بے وقوف ہیں |
| | یقیناً وہ ہی فساد کرنے والے ہیں |
| | (اللہ نے فرمایا) یقیناً میں ہی اللہ ہوں |

ذیل جملے میں حصر کا مفہوم پیدا کر کے إِنَّ اور لامِ تاکید کا اضافہ کریں:
آخِرَی گھر (آخر کا گھر) زندگی ہے۔ <span dir="rtl">الدَّارُ الْآخِرَةُ حَيَوَانٌ</span>

مبتدا اور خبر کے درمیان حالتِ رفع والی ضمیر اس وقت بھی استعمال کی جاتی ہے جب خبر معرف باللام ہو اور یہ التباس پیدا ہو کر یہ جملہ نہیں ہے بلکہ مرکب ناقص ہے مثلاً:

| | |
|---|---|
| هٰذَا الرَّجُلُ | هٰذَا هُوَ الرَّجُلُ |
| ذَلِكَ الْفَوْزُ الْعَظِيمُ | ذَلِكَ هُوَ الْفَوْزُ الْعَظِيمُ |

یہ ضمیر ضمیر الفصل کہلاتی ہے۔ اس صورت میں اس کا استعمال ضروری بھی نہیں ہے جیسے قرآن میں ہے:
ذَلِكَ الْيَوْمُ الْحَقُّ
ذَلِكَ الْفَوْزُ الْعَظِيمُ
اللَّهُ الصَّمَدُ
یہ تینوں تراکیب مکمل جملے ہیں۔ مرکبات ناقصہ نہیں ہیں۔

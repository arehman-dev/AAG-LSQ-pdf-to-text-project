لسان القرآن

## مشق

| اَلطَّالِبُ جَالِسٌ | اَلطَّالِبَانِ جَالِسَانِ | اَلطُّلَّابُ جَالِسُونَ |

| اَلْمُؤْمِنُ صَادِقُ | | |
| اَلْمُنَافِقُ كَاذِبُ | | |
| اَلرَّجُلُ مُسْلِمُ | | |

| اَلْبِنْتُ بَاكِيَةٌ | | |

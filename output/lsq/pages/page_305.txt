## فعلِ مجہول (ناقص)

### ماضی

| | | واحد | مثنیٰ | جمع |
| :--- | :--- | :--- | :--- | :--- |
| غائب (3rd Person) | مذکر | دُعِیَ | دُعِیَا | دُعُوْا |
| | مؤنث | دُعِیَتْ | دُعِیَتَا | دُعِیْنَ |
| حاضر (2nd Person) | مذکر | دُعِیْتَ | دُعِیْتُمَا | دُعِیْتُمْ |
| | مؤنث | دُعِیْتِ | دُعِیْتُمَا | دُعِیْتُنَّ |
| متکلم (1st Person) | مذکر/مؤنث | دُعِیْتُ | | دُعِیْنَا |

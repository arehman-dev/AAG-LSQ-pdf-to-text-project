بعض مرتبہ جملہ اسمیہ میں خبر موجود نہیں ہوتی اس صورت میں متعلق خبر اس کی جگہ لے لیتا ہے ایسی صورت میں متعلق خبر کو قائم مقام خبر یا صرف خبر کہتے ہیں۔

| اردو ترجمہ | عربی عبارت |
| :--- | :--- |
| آدمی گھر میں ہے | الرَّجُلُ فِي الْبَيْتِ |
| تمام تعریفیں اللہ کی ہیں | اَلْحَمْدُ لِلّٰهِ |
| جنت متقیوں کے لیے ہے | اَلْجَنَّةُ لِلْمُتَّقِينَ |
| جہنم کافروں کے لیے ہے | جَهَنَّمُ لِلْكَافِرِينَ |
| حیاء ایمان میں سے ہے | اَلْحَيَاءُ مِنَ الْإِيْمَانِ |
| تمام انسان ایک بڑے خسارے میں ہے | اَلْإِنْسَانُ فِي خُسْرٍ |
| میرا گھر مسجد کے سامنے ہے | بَيْتِي أَمَامَ الْمَسْجِدِ |
| گاڑی درخت کے نیچے ہے | اَلسَّيَّارَةُ تَحْتَ الشَّجَرَةِ |

أَمَامَ، خَلْفَ، فَوْقَ، تَحْتَ، عِنْدَ جیسے الفاظ ظرف کہلاتے ہیں۔

بعض مرتبہ قائم مقام خبر کو مبتدا پر مقدم کر دیا جاتا ہے جس سے جملے میں ایک طرح کی تاکید پیدا ہو جاتی ہے مثلاً

| اردو ترجمہ | عربی عبارت |
| :--- | :--- |
| آسمانوں اور زمین کی بادشاہت اللہ ہی کی ہے | لِلّٰهِ مُلْكُ السَّمٰوٰتِ وَالْأَرْضِ |
| آسمانوں اور زمین کے خزانے اللہ ہی کے ہیں | لِلّٰهِ خَزَائِنُ السَّمٰوٰتِ وَالْأَرْضِ |
| تمہارا لوٹنا ہماری ہی طرف ہے | اِلَيْنَا مَرْجِعُكُمْ |

نوٹ: جار مجرور اور ظرف جملہ اسمیہ میں خبر تو بن سکتے ہیں لیکن مبتدا نہیں۔ عربی زبان میں کوئی جملہ جار مجرور یا ظرف سے شروع ہو رہا ہو تو اس کے بعد آنے والا اسم مبتدا ہوتا ہے اگرچہ نکرہ ہو

| اردو ترجمہ | عربی عبارت |
| :--- | :--- |
| (گھر میں ایک آدمی ہے) | فِي الْبَيْتِ رَجُلٌ |
| (تنگی کے ساتھ ایک آسانی ہے) | مَعَ الْعُسْرِ يُسْرٌ |
| (جسم میں ایک لوتھڑا ہے) | فِي الْجَسَدِ مُضْغَةٌ |
| | لَهُمْ عَذَابٌ عَظِيمٌ |

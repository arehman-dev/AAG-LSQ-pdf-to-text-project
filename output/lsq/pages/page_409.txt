| میں نے اپنے دوست کی مدد کی | نَصَرْتُ صَدِيْقِيْ |
| اے ہمارے رب! ہم نے اپنی جانوں پر ظلم کیا | رَبَّنَا ظَلَمْنَا أَنْفُسَنَا |
| اللہ نے ہماری مدد کی | نَصَرَنَا اللهُ |
| تو نے اُس کو مارا | نَصَرْتَهُ |
| تم (سب مؤنث) نے اُس (مذکر) کی مدد کی | نَصَرْتُنَّهُ |
| تم دونوں نے حامد کا قلم چرایا | سَرَقْتُمَا قَلَمَ حَامِدٍ |
| زید کے بھائی نے تم دونوں کو طلب کیا | طَلَبَكُمَا أَخُوْ زَيْدٍ |
| مسلمانوں نے گائے کو ذبح کیا اور اس کا گوشت کھایا | ذَبَحَ الْمُسْلِمُوْنَ الْبَقَرَةَ وَأَكَلُوْا لَحْمَهَا |
| دو چور گھر میں داخل ہوئے اور انھوں نے مال چرایا | دَخَلَ السَّارِقَانِ فِي الْبَيْتِ وَسَرَقَا الْمَالَ |
| موسیٰ اپنی قوم کی طرف لوٹے | رَجَعَ مُوْسَى إِلَى قَوْمِهِ |
| تیرے لڑکے نے مجھے مارا | ضَرَبَنِيْ وَلَدُكَ |
| حامد اور محمود مدرسہ میں آئے اور اپنا سبق یاد کیا | قَدِمَ حَامِدٌ وَمَحْمُوْدٌ فِي الْمَدْرَسَةِ وَحَفِظَا دَرْسَهُمَا |
| فاطمہ اور زینب گھر میں داخل ہوئیں اور انہوں نے کھانا کھایا | دَخَلَتْ فَاطِمَةُ وَزَيْنَبُ فِي الْبَيْتِ وَأَكَلَتَا الطَّعَامَ |
| کچھ مرد آئے، وہ بیٹھے پھر چلے گئے | قَدِمَ رِجَالٌ فَجَلَسُوْا ثُمَّ ذَهَبُوْا |
| تم (سب) نے چھوٹے لڑکے کو مارا | ضَرَبْتُمُ الْوَلَدَ الصَّغِيْرَ |
| اللہ نے موسیٰ کو فرعون کی طرف بھیجا | بَعَثَ اللهُ مُوْسَى إِلَى فِرْعَوْنَ |
| ابراہیم کے چھوٹے لڑکے نے زید کے بڑے لڑکے کو مارا | ضَرَبَ وَلَدُ إِبْرَاهِيْمَ الصَّغِيْرُ وَلَدَ زَيْدٍ الْكَبِيْرَ |

| زید نے تمہاری کتاب نہیں چرائی | (سَرَقَ) مَا سَرَقَ زَيْدٌ كِتَابَكَ |

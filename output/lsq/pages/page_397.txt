## قَائِمٌ

| | | |
| :--- | :--- | :--- |
| هُوَ قَائِمٌ | هُمَا قَائِمَانِ | هُمْ قَائِمُونَ |
| هِيَ قَائِمَةٌ | هُمَا قَائِمَتَانِ | هُنَّ قَائِمَاتٌ |
| أَنْتَ قَائِمٌ | أَنْتُمَا قَائِمَانِ | أَنْتُمْ قَائِمُونَ |
| أَنْتِ قَائِمَةٌ | أَنْتُمَا قَائِمَتَانِ | أَنْتُنَّ قَائِمَاتٌ |
| أَنَا قَائِمٌ | نَحْنُ قَائِمَانِ | نَحْنُ قَائِمُونَ |
| أَنَا قَائِمَةٌ | نَحْنُ قَائِمَتَانِ | نَحْنُ قَائِمَاتٌ |

مضاعف ثلاثی مجرد کے تین ابواب سے استعمال ہوتا ہے۔

۱۔ نَصَرَ یَنْصُرُ مثلاً ضَرَّ یَضُرُّ سے ضَرَّ یَضُرُّ
۲۔ ضَرَبَ یَضْرِبُ مثلاً فَرَّ یَفِرُّ سے فَرَّ یَفِرُّ
۳۔ سَمِعَ یَسْمَعُ مثلاً مَسِسَ یَمْسَسُ سے مَسَّ یَمَسُّ

| | | |
| :--- | :--- | :--- |
| ض ر ر | (ن) | بِسْمِ اللّٰہِ الَّذِیْ لَا یَضُرُّ مَعَ اسْمِہٖ شَیْءٌ فِی الْاَرْضِ وَلَا فِی السَّمَاءِ وَھُوَ السَّمِیْعُ الْعَلِیْمُ |
| د ع ع | (ن) | یَدُعُّ الْیَتِیْمَ |
| ح ض ض | (ن) | وَلَا یَحُضُّ عَلٰی طَعَامِ الْمِسْکِیْنِ |
| ت ب ب | (ن) | تَبَّتْ یَدَا اَبِیْ لَہَبٍ وَّتَبَّ |
| ق ص ص | (ن) | نَحْنُ نَقُصُّ عَلَیْکَ اَحْسَنَ الْقَصَصِ |
| م ن ن | (ن) | قَدْ مَنَّ اللّٰہُ عَلَیْنَا |
| ف ر ر | (ض) | یَوْمَ یَفِرُّ الْمَرْءُ مِنْ اَخِیْہِ وَاُمِّہٖ وَاَبِیْہِ وَصَاحِبَتِہٖ وَبَنِیْہِ |
| م ر س | (س) | وَلَقَدْ خَلَقْنَا السَّمٰوٰتِ وَالْاَرْضَ وَمَا بَیْنَہُمَا فِیْ سِتَّۃِ اَیَّامٍ وَّمَا مَسَّنَا مِنْ لُّغُوْبٍ |

مضاعف ثلاثی مزید فیہ کے تمام ابواب سے استعمال ہوتا ہے سوائے اِفْعَلَّ اور اِفْعَالَّ۔

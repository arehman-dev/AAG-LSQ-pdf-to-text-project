صفحہ نمبر (68)

| مفرد (واحد) | مثنیٰ | جمع |
| :--- | :--- | :--- |
| هٰذَا مُسْلِمٌ | هٰذَانِ مُسْلِمَانِ | هٰؤُلَاءِ مُسْلِمُوْنَ |
| هٰذِهِ مُسْلِمَةٌ | هَاتَانِ مُسْلِمَتَانِ | هٰؤُلَاءِ مُسْلِمَاتٌ |
| ذٰلِكَ مُهَنْدِسٌ | ذَانِكَ مُهَنْدِسَانِ | أُولٰئِكَ مُهَنْدِسُوْنَ |
| تِلْكَ مُهَنْدِسَةٌ | تَانِكَ مُهَنْدِسَتَانِ | أُولٰئِكَ مُهَنْدِسَاتٌ |
| هٰذَا كِتَابٌ | هٰذَانِ كِتَابَانِ | هٰذِهِ كُتُبٌ |
| هٰذَا قَلَمٌ | هٰذَانِ قَلَمَانِ | هٰذِهِ أَقْلَامٌ |
| هٰذِهِ كُرَّاسَةٌ | هَاتَانِ كُرَّاسَتَانِ | هٰذِهِ كُرَّاسَاتٌ |
| ذٰلِكَ بَابٌ | ذَانِكَ بَابَانِ | تِلْكَ أَبْوَابٌ |
| تِلْكَ سَاعَةٌ | تَانِكَ سَاعَتَانِ | تِلْكَ سَاعَاتٌ |
| هٰذَا حِمَارٌ | هٰذَانِ حِمَارَانِ | هٰذِهِ حُمُرٌ |
| هٰذِهِ نَاقَةٌ | هَاتَانِ نَاقَتَانِ | هٰذِهِ نُوْقٌ |
| ذٰلِكَ جَبَلٌ | ذَانِكَ جَبَلَانِ | تِلْكَ جِبَالٌ |
| تِلْكَ سَيَّارَةٌ | تَانِكَ سَيَّارَتَانِ | تِلْكَ سَيَّارَاتٌ |
| هٰذَا سَرِيْرٌ | هٰذَانِ سَرِيْرَانِ | هٰذِهِ سُرُرٌ |
| هٰذِهِ دَرَّاجَةٌ | هَاتَانِ دَرَّاجَتَانِ | هٰذِهِ دَرَّاجَاتٌ |

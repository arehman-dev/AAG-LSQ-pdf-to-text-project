## مشق

مندرجہ ذیل جملوں پر إِنَّ اور لامِ تاکید استعمال کریں۔

| | |
| --- | --- |
| | بَطْشُ رَبِّكَ شَدِيدٌ |
| | اَلْمُنَافِقُونَ كَاذِبُونَ |
| | اَلْإِنْسَانُ فِي خُسْرٍ |
| | اَلْأَبْرَارُ فِي نَعِيمٍ |
| | اَلْفُجَّارُ فِي جَحِيمٍ |
| | اَلْإِنْسَانُ لِرَبِّهِ كَنُودٌ |
| | رَبُّهُمْ بِهِمْ يَوْمَئِذٍ خَبِيرٌ |
| | اِلْهَكُمُ وَاحِدٌ |
| | أَنْكَرَ الْأَصْوَاتِ لَصَوْتُ الْحَمِيرِ |
| | رَبِّي سَمِيعُ الدُّعَاءِ |
| | هُوَ عَلَى ذَلِكَ شَهِيدٌ |
| | هُوَ لَحُبِّ الْخَيْرِ لَشَدِيدٌ |
| | اَنْتَ رَسُولُ اللهِ |
| | اَنْتَ رَسُولُهُ |
| | هَذَا فِي الصُّحُفِ الْأُولَى |
| | فِي ذَلِكَ عِبْرَةٌ |
| | فِي السَّمَوَاتِ وَالْأَرْضِ لَآيَاتٍ لِلْمُؤْمِنِينَ |

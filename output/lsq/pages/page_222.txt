## جملہ اسمیہ میں تخصیص یا حصر کا مفہوم پیدا کرنا

جملہ اسمیہ میں تخصیص یا حصر یعنی "ہی" کا مفہوم پیدا کرنے کے لیے:

* مبتدا اور خبر کے درمیان حالتِ رفع والی ضمیر لائیں جو مبتدا کے مطابق ہو۔
* خبر کو معرفہ بنا دیں (اگر معرفہ نہ ہو) مثلاً

1. اَللّٰهُ غَفُوْرٌ
i. اَللّٰهُ هُوَ غَفُوْرٌ
ii. اَللّٰهُ هُوَ الْغَفُوْرُ (اللہ ہی بخشنے والا ہے)

2. اَلْقُرْاٰنُ حَقٌّ
i. اَلْقُرْاٰنُ هُوَ حَقٌّ (قرآن ہی حق ہے)
ii. اَلْقُرْاٰنُ هُوَ الْحَقُّ

درج ذیل جملوں میں حصر کا مفہوم پیدا کریں:

| :--- | :--- |
| اُولٰٓئِكَ مُفْلِحُوْنَ | |
| اَلْکٰفِرُوْنَ ظَالِمُوْنَ | |
| اَصْحٰبُ الْجَنَّةِ فَائِزُوْنَ | |
| هٰذَا کِتَابُكَ | |
| اَلْاٰخِرَةُ دَارُ الْقَرَارِ | |

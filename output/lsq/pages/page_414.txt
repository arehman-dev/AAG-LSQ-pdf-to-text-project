## صفحہ نمبر (172)

| | |
| :--- | :--- |
| جَلَسَ الْوَلَدَانِ اَمَامَ الْمُعَلِّمِ | اَلْوَلَدَانِ جَلَسَا اَمَامَ الْمُعَلِّمِ |
| نَصَرَ الْمُسْلِمُونَ اِخْوَانَهُمْ | اَلْمُسْلِمُونَ نَصَرُوْا اِخْوَانَهُمْ |
| شَرِبَ الْاَوْلَادُ اللَّبَنَ | اَلْاَوْلَادُ شَرِبُوْا اللَّبَنَ |
| اَكَلَ الْمُسَافِرُونَ الطَّعَامَ | اَلْمُسَافِرُونَ اَكَلُوْا الطَّعَامَ |
| كَتَبْتُ رِسَالَةً اِلَى اَخِيْ | اَنَا كَتَبْتُ رِسَالَةً اِلَى اَخِيْ |
| اَفَعَلْتَ هٰذَا يَا اِبْرَاهِيْمُ؟ | اَاَنْتَ فَعَلْتَ هٰذَا يَا اِبْرَاهِيْمُ؟ |
| سَمِعَ النَّاسُ كَلَامَ الْخَطِيْبِ | اَلنَّاسُ سَمِعُوْا كَلَامَ الْخَطِيْبِ |
| دَخَلَ الْوَلَدَانِ الصَّالِحَانِ فِي الْمَسْجِدِ | اَلْوَلَدَانِ الصَّالِحَانِ دَخَلَا فِي الْمَسْجِدِ |
| خَرَجَ فَاطِمَةُ وَ زَيْنَبُ وَ حَامِدٌ مِنَ الْبَيْتِ | فَاطِمَةُ وَ زَيْنَبُ وَ حَامِدٌ خَرَجُوْا مِنَ الْبَيْتِ |
| رَجَعَتِ الْبَنَاتُ مِنَ الْمَدْرَسَةِ | اَلْبَنَاتُ رَجَعْنَ مِنَ الْمَدْرَسَةِ |
| طَلَبَ الْمُدِيْرُ الطُّلَّابَ | اَلْمُدِيْرُ طَلَبَ الطُّلَّابَ |
| دَخَلَ السَّارِقَانِ فِي الْبَيْتِ | اَلسَّارِقَانِ دَخَلَا فِي الْبَيْتِ |
| خُلِقَ الْاِنْسَانُ مِنْ طِيْنٍ | اَلْاِنْسَانُ خُلِقَ مِنْ طِيْنٍ |
| نَصَرَ الْمُسْلِمُونَ | اَلْمُسْلِمُونَ نَصَرُوْا |
| طَلَبَ الطَّالِبُ | اَلطَّالِبُ طَلَبَ |
| دَخَلَ فِي الْبَيْتِ | هُوَ دَخَلَ فِي الْبَيْتِ |
| خَرَجُوْا مِنَ الْمَسْجِدِ | هُمْ خَرَجُوْا مِنَ الْمَسْجِدِ |
| ذَهَبْتُ اِلَى اُمِّهَا | هِيَ ذَهَبَتْ اِلَى اُمِّهَا |
| فَتَحْتُ الْبَابَ | اَنَا فَتَحْتُ الْبَابَ |
| شَرِبْنَا الْمَاءَ | نَحْنُ شَرِبْنَا الْمَاءَ |

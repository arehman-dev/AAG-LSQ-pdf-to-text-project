## صفحہ (201)

| | |
| :--- | :--- |
| أُولَٰئِكَ مُفْلِحُونَ | أُولَٰئِكَ هُمُ الْمُفْلِحُونَ |
| الْكَافِرُونَ ظَالِمُونَ | الْكَافِرُونَ هُمُ الظَّالِمُونَ |
| أَصْحَابُ الْجَنَّةِ فَائِزُونَ | أَصْحَابُ الْجَنَّةِ هُمُ الْفَائِزُونَ |
| هَٰذَا كِتَابُكَ | هَٰذَا هُوَ كِتَابُكَ |
| الْآخِرَةُ دَارُ الْقَرَارِ | الْآخِرَةُ هِيَ دَارُ الْقَرَارِ |

## صفحہ (222)

عربی میں ترجمہ کریں:

| | |
| :--- | :--- |
| یقیناً اللہ ہی بخشنے والا رحم کرنے والا ہے | إِنَّ اللَّهَ هُوَ الْغَفُورُ الرَّحِيمُ |
| یقیناً تو ہی توبہ قبول کرنے والا رحم کرنے والا ہے | إِنَّكَ أَنْتَ التَّوَّابُ الرَّحِيمُ |
| یقیناً وہ ہی سننے والا جاننے والا ہے | إِنَّهُ هُوَ السَّمِيعُ الْعَلِيمُ |
| یقیناً وہ ہی بے وقوف ہیں | إِنَّهُمْ هُمُ السُّفَهَاءُ |
| یقیناً وہ ہی فساد کرنے والے ہیں | إِنَّهُمْ هُمُ الْمُفْسِدُونَ |
| یقیناً میں ہی اللہ ہوں | إِنَّنِي أَنَا اللَّهُ |

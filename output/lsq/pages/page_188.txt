## اَلْأَلِفُ التَّانِيْثِ

حصہ اول میں ہم مؤنث کی علامات میں سے تائے مربوطہ (گول تاء) کے بارے میں پڑھ چکے ہیں، اس حصے میں مؤنث کی دوسری علامت الف التانیث کے بارے میں پڑھا جائے گا۔

الف التانیث سے مراد تانیث والا الف ہے۔ اس کی دو قسمیں ہیں۔

① أَلِفُ التَّانِيْثِ الْمَقْصُوْرَةُ (الف المقصورۃ للتانیث)

| رُجْعٰی | - | كُبْرٰی | - | حُبْلٰی | مثلاً: |
| --- | --- | --- | --- | --- | --- |
| دَعْوٰی | - | كَسْلٰی | - | مَرْضٰی | |
| | | ذِكْرٰی | - | سُكَارٰی | |

② أَلِفُ التَّانِيْثِ الْمَمْدُوْدَةُ (الف الحمد وۃ للتانیث)

| خَضْرَاء | - | صَفْرَاء | - | حَمْرَاء | مثلاً: |
| --- | --- | --- | --- | --- | --- |
| | | بُكْمَاء | - | عَرْجَاء | |
| | | | | صَحْرَاء | |

یادرہے کہ الف مقصورہ وہ الف ہے جو کلمہ کے آخر میں آتا ہے اور اس سے پہلے لازماً فتحہ یعنی زبر ہوتا ہے۔ اسے مقصورہ اس لیے کہا جاتا ہے کہ اس کو پڑھنے میں لمبا نہیں کیا جاتا۔ نیز مؤنث کی علامت کے طور پر یہ ہمیشہ زائدہ ہوتا ہے۔ اور اسم (حُبْلٰی - ایک بوئی)، صفت (كُبْرٰی - سب سے بڑی)، جمع (مَرْضٰی - مریض) اور مصدر (رُجْعٰی - لوٹنا) کے آخر میں آتا ہے۔

الف مقصورہ کے ساتھ مؤنث بننے والے اسماء کے چند اوزان درج ذیل ہیں۔

فُعْلٰی - فُعْلٰی - فُعْلٰی - فُعَالٰی

جبکہ الف ممدودہ اسم کے آخر میں آنے والے دو زائد الفوں کے اس مجموعے کو کہا جاتا ہے جن میں سے دوسرے الف کو ہمزہ سے تبدیل کر دیا جاتا ہے۔ اسے ممدودہ اس لیے کہا جاتا ہے کہ اس الف پر مد کی جاتی ہے یعنی قراءۃ میں اسے تین الف کے برابر لمبا پڑھا جاتا ہے۔

الف الممد وۃ للتانیث اسم (صَحْرَاء - جنگل)، مصدر (رَغْبَاء - رغبت) اور صفت (زَرْقَاء - نیلی، عَرْجَاء - لنگڑی) کے آخر میں آتا ہے اور اس کا مشہور وزن فَعْلَاء ہے۔

## اِسْمُ الصِّفَةِ

ایسا اسمِ مشتق جو مستقل طور پر کسی اسم کی وقتی یا دائمی صفت کو ظاہر کرے اِسْمُ الصِّفَةِ یا صفتِ مشبہ کہلاتا ہے۔

### اِسْمُ الصِّفَةِ کے اوزان

اِسْمُ الصِّفَةِ کے کئی اوزان ہیں۔

| وزن | مثال | معنی |
| :--- | :--- | :--- |
| فَعْلٌ | صَعْبٌ | (مشکل) |
| فِعْلٌ | صِفْرٌ | (خالی) |
| فُعْلٌ | حُلْوٌ | (میٹھا) |
| فَعَلٌ | حَسَنٌ | (اچھا) |
| فَعِلٌ | فَرِحٌ | (خوش) |
| فُعُلٌ | | |
| فَعَالٌ | جَبَانٌ | (بزدل) |
| فُعَالٌ | شُجَاعٌ | (بہادر) |
| فَعِيلٌ | كَرِيمٌ - سَمِيعٌ - حَرِيصٌ - رَحِيمٌ - بَصِيرٌ | |

فَعِيلٌ کے وزن میں کبھی اسم الفاعل کا مفہوم ہوتا ہے اور کبھی اسم المفعول کا

| اسم الفاعل | معنی | اسم المفعول | معنی |
| :--- | :--- | :--- | :--- |
| سَمِيعٌ | سننے والا | بَصِيرٌ | دیکھنے والا |
| قَتِيلٌ | قتل کیا ہوا | رَحِيمٌ | رحم کیا ہوا |

مندرجہ بالا اوزان ایک درخت کے تنے کی مانند ہیں اس سے نکلنے والی شاخیں درج ذیل ہیں۔

① **اِسْمُ الْمُبَالَغَةِ:**
اسم الصفتہ کی وہ قسم جس میں کسی کام کی کثرت یا زیادتی کا مفہوم پایا جائے اسم المبالغہ میں بھی زیادہ تر "کام کرنے والا" کا ہی مفہوم ہوتا ہے لیکن کام کی کثرت اور زیادتی کے ساتھ۔

ح م د: حَامِدٌ (اسم الفاعل) ، حَمَّادٌ (اسم المبالغہ)

اسم المبالغہ کے بھی کئی اوزان ہیں جن میں سے زیادہ استعمال ہونے والے اوزان درج ذیل ہیں۔

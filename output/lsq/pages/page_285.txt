## فعل مجہول (مثال)

| ماضی | واحد | مثنیٰ | جمع |
| :--- | :--- | :--- | :--- |
| غائب (3rd Person) | مذکر | وُلِدَ | وُلِدَا | وُلِدُوا |
| | مؤنث | وُلِدَتْ | وُلِدَتَا | وُلِدْنَ |
| حاضر (2nd Person) | مذکر | وُلِدْتَ | وُلِدْتُمَا | وُلِدْتُمْ |
| | مؤنث | وُلِدْتِ | وُلِدْتُمَا | وُلِدْتُنَّ |
| متکلم (1st Person) | مذکر | وُلِدْتُ | | وُلِدْنَا |
| | مؤنث | وُلِدْتُ | | وُلِدْنَا |

| مضارع | واحد | مثنیٰ | جمع |
| :--- | :--- | :--- | :--- |
| غائب (3rd Person) | مذکر | يُولَدُ | يُولَدَانِ | يُولَدُونَ |
| | مؤنث | تُولَدُ | تُولَدَانِ | يُولَدْنَ |
| حاضر (2nd Person) | مذکر | تُولَدُ | تُولَدَانِ | تُولَدُونَ |
| | مؤنث | تُولَدِينَ | تُولَدَانِ | تُولَدْنَ |
| متکلم (1st Person) | مذکر | أُولَدُ | | نُولَدُ |
| | مؤنث | أُولَدُ | | نُولَدُ |

# الف مقصورہ اور الف ممدودہ والے اسماء کا مثنیٰ اور جمع

## اسمِ ممدود

جس اسم کے آخر میں الف اور ہمزہ ہو اسے اسمِ ممدود کہتے ہیں۔ اگر اسمِ ممدود میں ہمزہ اصلی ہو یعنی مادے کا حرف ہو تو مثنیٰ بناتے ہوئے ہمزہ برقرار رہتا ہے جیسے:

| سے | ابْتِدَاءٌ |
| :---: | :---: |
| اِبْتِدَاءَانِ | سے |
| رِفَاءٌ | سے |
| رِفَاءَانِ | سے |

لیکن اگر ہمزہ تانیث کا ہو تو اسے واو میں بدل دیا جاتا ہے جیسے:

| سے | صَحْرَاءُ |
| :---: | :---: |
| صَحْرَاوَانِ | سے |
| حَمْرَاءُ | سے |
| حَمْرَاوَانِ | سے |

لیکن اگر ہمزہ نہ تو اصلی ہو اور نہ ہی تانیث کے لیے ہو تو اسے برقرار رکھنا یا واو سے بدلنا دونوں طرح درست ہے جیسے:

| سے | سَمَاءُ |
| :---: | :---: |
| سَمَاءَانِ یا سَمَاوَانِ | سے |

جو اسمِ ممدود مذکر ہوگا اس سے جمع سالم مذکر آئے گی اور جو مؤنث ہوگا اس سے جمع سالم مؤنث آئے گی جیسے:

| سے | رِفَاءُ |
| :---: | :---: |
| رِفَاءُونَ | سے |
| سَمَاءُ | سے |
| سَمَاوَاتٌ | سے |

اور وہ صفات جو الوان و عیوب سے بحث کرتی ہیں ان کی جمع مکستر آئے گی۔ الوان و عیوب والی مؤنث صفات کا چارٹ درج ذیل ہے۔

| جَرّ | نَصْب | رَفْع | |
| :---: | :---: | :---: | :---: |
| فَعْلَاءَ | فَعْلَاءَ | فَعْلَاءُ | واحد |
| فَعْلَاوَيْنِ | فَعْلَاوَيْنِ | فَعْلَاوَانِ | مثنیٰ |
| فُعْلٍ | فُعْلًا | فُعْلُ | جمع |

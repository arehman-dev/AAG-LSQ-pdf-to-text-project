صفحہ نمبر (80)

| | | | |
| :--- | :--- | :--- | :--- |
| اللہ کا گھر | بَيْتُ اللهِ | اللہ کی کتاب | كِتَابُ اللهِ |
| اللہ کا بندہ | عَبْدُ اللهِ | اللہ کی مدد | نَصْرُ اللهِ |
| نماز کا قائم کرنے والا | مُقِيمُ الصَّلٰوةِ | جمعہ کا دن | يَوْمُ الْجُمُعَةِ |
| غیب کا جاننے والا | عَالِمُ الْغَيْبِ | مومن کی معراج | مِعْرَاجُ الْمُؤْمِنِ |
| مومن کی جیل | سِجْنُ الْمُؤْمِنِ | کافر کی جنت | جَنَّةُ الْكَافِرِ |
| کسی راستے کا پار کرنے والا | عَابِرُ السَّبِيلِ | لڑکے کی دو کتابیں | كِتَابَا الْوَلَدِ |
| زید کے دونوں گھر | بَيْتَا زَيْدٍ | مسلمانوں کا گھر | بَيْتُ الْمُسْلِمِينَ |
| تمام جہانوں کا رب | رَبُّ الْعَالَمِينَ | تمام انسانوں کا بادشاہ | مَلِكُ النَّاسِ |

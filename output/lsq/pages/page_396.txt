## صفحہ نمبر (71)

| | | |
| :--- | :--- | :--- |
| هُوَ مُسْلِمٌ | هُمَا مُسْلِمَانِ | هُمْ مُسْلِمُونَ |
| هِيَ مُسْلِمَةٌ | هُمَا مُسْلِمَتَانِ | هُنَّ مُسْلِمَاتٌ |
| أَنْتَ مُسْلِمٌ | أَنْتُمَا مُسْلِمَانِ | أَنْتُمْ مُسْلِمُونَ |
| أَنْتِ مُسْلِمَةٌ | أَنْتُمَا مُسْلِمَتَانِ | أَنْتُنَّ مُسْلِمَاتٌ |
| أَنَا مُسْلِمٌ | نَحْنُ مُسْلِمَانِ | نَحْنُ مُسْلِمُونَ |
| أَنَا مُسْلِمَةٌ | نَحْنُ مُسْلِمَتَانِ | نَحْنُ مُسْلِمَاتٌ |

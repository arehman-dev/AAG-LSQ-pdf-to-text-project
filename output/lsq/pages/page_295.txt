کَانَ اگرچہ فعلِ ناقص ہے لیکن اس پر فعل کے قواعد کا اطلاق ہوتا ہے یعنی فاعل اگر اسمِ ظاہر ہے تو فعل ہمیشہ واحد آئے گا خواہ فاعل واحد ہو، مثنیٰ ہو یا جمع ہو۔

| | |
| :--- | :--- |
| کَانَ الْمُعَلِّمُ قَائِمًا | کَانَتِ الْمُعَلِّمَةُ قَائِمَةً |
| کَانَ الْمُعَلِّمَانِ قَائِمَیْنِ | کَانَتِ الْمُعَلِّمَتَانِ قَائِمَتَیْنِ |
| کَانَ الْمُعَلِّمُونَ قَائِمِینَ | کَانَتِ الْمُعَلِّمَاتُ قَائِمَاتٍ |

فاعل اگر اسمِ ضمیر ہو تو فعل کی گردان چلے گی:

| | |
| :--- | :--- |
| کَانَ قَائِمًا | کُنْتُ قَائِمًا | کُنْتُ قَائِمًا/قَائِمَةً |
| کَانَا قَائِمَیْنِ | کُنْتُمَا قَائِمَیْنِ | کُنَّا قَائِمَیْنِ/قَائِمَاتٍ |
| کَانُوا قَائِمِینَ | کُنْتُمْ قَائِمِینَ | |
| کَانَتْ قَائِمَةً | کُنْتِ قَائِمَةً | |
| کَانَتَا قَائِمَتَیْنِ | کُنْتُمَا قَائِمَتَیْنِ | |
| کُنَّ قَائِمَاتٍ | کُنْتُنَّ قَائِمَاتٍ | |

کَانَ اور یَکُونُ فعل کے ساتھ بھی استعمال ہوتے ہیں۔ فعل کے ساتھ استعمال کی صورتیں درج ذیل ہیں۔

۱۔ کَانَ + فعلِ ماضی = ماضی بعید
کَانَ کَتَبَ (اس نے لکھا تھا)
کَانَ اور فعل (ماضی) دونوں کی گردان ساتھ چلے گی

۲۔ کَانَ + فعلِ مضارع = ماضی استمراری
کَانَ یَکْتُبُ (وہ لکھتا تھا یا لکھا کرتا تھا)
کَانَ اور فعل (مضارع) دونوں کی گردان ساتھ چلے گی

۳۔ یَکُونُ + فعلِ ماضی = ماضی شکیہ
یَکُونُ کَتَبَ (اس نے لکھا ہوگا)
یَکُونُ اور فعل (ماضی) دونوں کی گردان ساتھ چلے گی

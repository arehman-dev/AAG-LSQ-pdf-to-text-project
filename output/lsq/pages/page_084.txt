اضافی میں حالت جر والے ضمائر استعمال ہوں گے مثلاً:

| اردو | عربی |
| :--- | :--- |
| زید کی کتاب | كِتَابُ زَيْدٍ |
| اُس کی کتاب | كِتَابُهُ |
| اُن (دو مذکر) کی کتاب | كِتَابُهُمَا |
| اُن (سب مذکر) کی کتاب | كِتَابُهُمْ |
| اُس (ایک مونث) کی کتاب | كِتَابُهَا |
| ان (دو مونث) کی کتاب | كِتَابُهُمَا |
| ان (سب مونث) کی کتاب | كِتَابُهُنَّ |
| تیری (ایک مذکر کی) کتاب | كِتَابُكَ |
| تمہاری (دومذکر کی) کتاب | كِتَابُكُمَا |
| تمہاری (سب مذکر کی) کتاب | كِتَابُكُمْ |
| تیری (مونث کی) کتاب | كِتَابُكِ |
| تمہاری (دومونث کی) کتاب | كِتَابُكُمَا |
| تمہاری (سب مونث کی) کتاب | كِتَابُكُنَّ |
| میری (ایک مذکر/مونث کی) کتاب | كِتَابِي |
| ہماری (دو/سب /مذکر/مونث کی) کتاب | كِتَابُنَا |

## واحد مذکر غائب کی ضمیر یعنی "ہُ":

واحد مذکر غائب کی ضمیر "ہُ" کو لکھنے اور پڑھنے کے مختلف طریقے ہیں اس کا عام اصول یہ ہے کہ اس ضمیر سے پہلے اگر:

* پیش یا زبر ہو تو ضمیر پر الٹا پیش آتا ہے جیسے كِتَابُهُ - كِتَابَهُ
* زیر ہو تو ضمیر پر کھڑی زیر آتی ہے جیسے كِتَابِهِ
* یاء ساکن ہو تو ضمیر پر زیر آتی ہے جیسے كِتَابَيْهِ
* کوئی اور حرف ساکن ہو یا الف ہو تو ضمیر پر سیدھا پیش آتا ہے جیسے كِتَابَاهُ - مِنْهُ

## حروفِ نداء

حصہ اوّل میں ہم حرفِ نداء "يَا" کے بارے میں پڑھ چکے ہیں اور "يَا" کے ساتھ مُنادیٰ کی مختلف صورتیں بھی دیکھ چکے ہیں۔

اس سبق میں ہم حروفِ نداء اور مُنادیٰ کے بارے میں مزید کچھ باتیں تفصیل سے پڑھیں گے۔

حرفِ نداء "يَا" کے علاوہ مزید پانچ اور حروفِ نداء کے لیے استعمال ہوتے ہیں جو درج ذیل ہیں۔

**أَيَا - هَيَا - أَيْ - آ - أَ**

ان میں سے پہلے چار حروف مُنادیٰ بعید کے لیے استعمال ہوتے ہیں جبکہ حرف "أَ" مُنادیٰ قریب کے لیے استعمال ہوتا ہے۔ یہ سب ایک دوسرے کی جگہ بھی استعمال ہو سکتے ہیں۔ حرفِ نداء "يَا" مُنادیٰ قریب اور بعید دونوں کے لیے استعمال ہوتا ہے۔

جو مُنادیٰ یائے متکلم کی طرف مضاف ہو اس کو چار طرح سے پڑھا جا سکتا ہے۔

| | | | |
| :--- | :--- | :--- | :--- |
| ۱۔ | یائے سکون کے ساتھ | جیسے | **يَا رَبِّي** |
| ۲۔ | یائے فتحہ کے ساتھ | جیسے | **يَا رَبِّيَ** |
| ۳۔ | یائے حذف کے ساتھ | جیسے | **يَا رَبِّ** |
| ۴۔ | یا کو الف سے بدلنے کے ساتھ | جیسے | **يَا رَبَّا** |

درج ذیل مقامات میں حرفِ نداء کا حذف کرنا جائز ہے:

| | | | |
| :--- | :--- | :--- | :--- |
| ۱۔ | مُنادیٰ علم ہو | جیسے | **يُوسُفُ أَعْرِضْ عَنْ هَذَا** |
| ۲۔ | مُنادیٰ معرف باللام ہو اَیُّ کے ساتھ | جیسے | **السَّلَامُ عَلَيْكَ أَيُّهَا النَّبِيُّ** |
| ۳۔ | مُنادیٰ مضاف ہو معرفہ کی طرف | جیسے | **رَبَّنَا آتِنَا فِي الدُّنْيَا حَسَنَةً** |

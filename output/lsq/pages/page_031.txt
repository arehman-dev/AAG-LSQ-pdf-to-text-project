## مشق

درج ذیل واحد اسماء کے مثنیٰ بنائیں۔

| مثنیٰ | واحد | مثنیٰ | واحد |
| :---: | :---: | :---: | :---: |
| | بِنْتٌ | | وَلَدٌ |
| | كَافِرٌ | | مُسْلِمٌ |
| | مُنَافِقٌ | | مُؤْمِنٌ |
| | أُسْتَاذَةٌ | | أُسْتَاذٌ |
| | طَالِبَةٌ | | طَالِبٌ |
| | مَكْتَبٌ | | كُرْسِيٌّ |
| | نَافِذَةٌ | | بَابٌ |
| | أُذُنٌ | | عَيْنٌ |
| | رَجُلٌ | | يَدٌ |
| | مَدْرَسَةٌ | | مَسْجِدٌ |

درج ذیل حدیث میں مثنیٰ اسماء کی نشاندہی کریں اور ان کے واحد اسماء لکھیں۔

كَلِمَتَانِ حَبِيبَتَانِ إِلَى الرَّحْمٰنِ، خَفِيفَتَانِ عَلَى اللِّسَانِ، ثَقِيلَتَانِ فِي الْمِيزَانِ
سُبْحَانَ اللَّهِ وَبِحَمْدِهِ، سُبْحَانَ اللَّهِ الْعَظِيمِ

صفحہ نمبر (77)

| | | | |
| :--- | :--- | :--- | :--- |
| یہ آدمی | هَذَا الرَّجُلُ | وہ لڑکا | ذٰلِكَ الْوَلَدُ |
| یہ دو معلم | هَذَانِ الْمُعَلِّمَانِ | وہ دو معلمات | تَانِكَ الْمُعَلِّمَتَانِ |
| یہ لڑکے | هٰؤُلَاءِ الْأَوْلَادُ | وہ عورتیں | أُولٰئِكَ النِّسَاءُ |
| یہ کتاب | هَذَا الْكِتَابُ | وہ کھڑکیاں | تِلْكَ النَّوَافِذُ |
| یہ کتابیں | هَذِهِ الْكُتُبُ | یہ شہر | هَذَا الْبَلَدُ |
| وہ نیک لڑکا | ذٰلِكَ الْوَلَدُ الصَّالِحُ | وہ اونچے پہاڑ | تِلْكَ الْجِبَالُ الشَّامِخَةُ |
| یہ امن والا شہر | هَذَا الْبَلَدُ الْأَمِينُ | یہ دنیاوی زندگی | هَذِهِ الْحَيَاةُ الدُّنْيَا |

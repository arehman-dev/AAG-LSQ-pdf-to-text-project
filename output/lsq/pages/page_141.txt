## مشق

عربی میں ترجمہ کریں۔

| اردو | عربی |
| :--- | :--- |
| ہم صبر کرتے ہیں | نَصْبِرُ |
| وہ ٹھنڈا پانی پیتے ہیں | يَشْرَبُونَ مَاءً بَارِدًا |
| ہم اللہ کی عبادت کرتے ہیں | نَعْبُدُ اللّٰهَ |
| میں اللہ کا ذکر کرتا ہوں | أَذْكُرُ اللّٰهَ |
| اللہ گناہوں کو بخش دیتا ہے | يَغْفِرُ اللّٰهُ الذُّنُوبَ |
| اللہ ہمیں رزق دیتا ہے | يَرْزُقُنَا اللّٰهُ |
| اللہ اسلام کے لیے ہمارا سینہ کھول دے گا | سَيَشْرَحُ اللّٰهُ صَدْرَنَا لِلْإِسْلَامِ |
| مسلمان گائے کو ذبح کریں گے | سَيَذْبَحُ الْمُسْلِمُونَ بَقَرَةً |

## مشق

② دی گئی مثال کے مطابق کالم مکمل کریں۔

| | | |
| :---: | :---: | :---: |
| هٰؤُلَاءِ مُسْلِمُونَ | هٰذَانِ مُسْلِمَانِ | هٰذَا مُسْلِمُ |
| | | هٰذِهِ مُسْلِمَةٌ |
| | | ذَلِكَ مُهَنْدِسُ |
| | | تِلْكَ مُهَنْدِسَةٌ |
| هٰذِهِ كُتُبُ | هٰذَانِ كِتَابَانِ | هٰذَا كِتَابُ |
| | | هٰذَا قَلَمُ |
| | | هٰذِهِ كُرّاسَةٌ |
| | | ذَلِكَ بَابُ |
| | | تِلْكَ سَاعَةٌ |
| | | هٰذَا حِمَارُ |
| | | هٰذِهِ نَاقَةٌ |
| | | ذَلِكَ جَبَلُ |
| | | تِلْكَ سَيّارَةٌ |
| | | هٰذَا سَرِيرُ |
| | | هٰذِهِ دَرّاجَةٌ |

## صفحہ نمبر (106)

| اردو ترجمہ | عربی عبارت | اردو ترجمہ | عربی عبارت |
| :--- | :--- | :--- | :--- |
| لڑکا محنتی نہیں ہے | مَا الْوَلَدُ مُجْتَهِدًا | لڑکا بالکل محنتی نہیں ہے | مَا الْوَلَدُ بِمُجْتَهِدٍ |
| وہ ہرگز مومن نہیں ہیں | مَا هُمْ بِمُؤْمِنِينَ | دونوں لڑکیاں سچی نہیں ہیں | مَا الْبِنْتَانِ صَادِقَتَيْنِ |
| لڑکے نیک نہیں ہیں | مَا الْأَوْلَادُ صَالِحِينَ | وہ ان کی مائیں نہیں ہیں | مَا هُنَّ أُمَّهَاتُهُمْ |
| تم ہرگز مجنوں نہیں ہو | مَا أَنْتَ بِمَجْنُونٍ | عورتیں جھوٹی نہیں ہیں | مَا النِّسَاءُ كَاذِبَاتٍ |
| طالبات حاضر نہیں ہیں | مَا الطَّالِبَاتُ حَاضِرَاتٍ | یہ منافق نہیں ہیں | مَا هُؤُلَاءِ مُنَافِقِينَ |

## صفحہ نمبر (110)

| اردو ترجمہ | عربی عبارت | اردو ترجمہ | عربی عبارت |
| :--- | :--- | :--- | :--- |
| کیا زید نیک ہے؟ | أَزَيْدٌ صَالِحٌ | ہاں وہ نیک ہے | نَعَمْ! هُوَ صَالِحٌ |
| کیا دونوں لڑکیاں سچی ہیں؟ | هَلِ الْبِنْتَانِ صَادِقَتَانِ | کیا استانیاں بیٹھی ہیں؟ | هَلِ الْمُعَلِّمَاتُ جَالِسَاتٌ |
| کیا حامد زید کا بیٹا ہے؟ | أَحَامِدٌ ابْنُ زَيْدٍ | | |

## صفحہ نمبر (116)

| اردو ترجمہ | عربی عبارت |
| :--- | :--- |
| وہ لڑکا جو مسجد میں ہے زید کا بھائی ہے | الْوَلَدُ الَّذِي فِي الْمَسْجِدِ أَخُو زَيْدٍ |
| وہ لڑکی جو معلمہ کے سامنے ہے ذہین ہے | الْبِنْتُ الَّتِي أَمَامَ الْمُعَلِّمَةِ ذَكِيَّةٌ |
| وہ لوگ جو مسجد میں ہیں نیک ہیں | النَّاسُ الَّذِينَ فِي الْمَسْجِدِ صَالِحُونَ |
| وہ کتاب جو میز پر ہے زید کی ہے | الْكِتَابُ الَّذِي فَوْقَ الْمَكْتَبِ لِزَيْدٍ |
| وہ عورتیں جو گھر میں ہیں مومنات ہیں | النِّسَاءُ اللَّاتِي فِي الْبَيْتِ مُؤْمِنَاتٌ |

## صفحہ نمبر (124)

| اردو ترجمہ | عربی عبارت | اردو ترجمہ | عربی عبارت |
| :--- | :--- | :--- | :--- |
| زید گیا | ذَهَبَ زَيْدٌ | حامد نے مدد کی | نَصَرَ حَامِدٌ |
| کسی گواہی دینے والے نے گواہی دی | شَهِدَ شَاهِدٌ | مسلمانوں نے سجدہ کیا | سَجَدَ الْمُسْلِمُونَ |
| تم نے ظلم کیا | ظَلَمْتُمْ | طالبات کامیاب ہوئیں | نَجَحَتِ الطَّالِبَاتُ |
| تم دونوں نے صبر کیا | صَبَرْتُمَا | ہم نے شکر کیا | شَكَرْنَا |
| معلمات بیٹھ گئیں | جَلَسَتِ الْمُعَلِّمَاتُ | اللہ نے سنا | سَمِعَ اللَّهُ |

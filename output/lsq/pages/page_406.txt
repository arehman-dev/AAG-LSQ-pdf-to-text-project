صفحہ نمبر (104)

| عربی عبارت | عربی عبارت |
| :--- | :--- |
| بَطْشُ رَبِّكَ شَدِيدٌ | إِنَّ بَطْشَ رَبِّكَ لَشَدِيدٌ |
| اَلْمُنَافِقُونَ كَاذِبُونَ | إِنَّ الْمُنَافِقِينَ لَكَاذِبُونَ |
| اَلْإِنْسَانُ فِي خُسْرٍ | إِنَّ الْإِنْسَانَ لَفِي خُسْرٍ |
| اَلْأَبْرَارُ فِي نَعِيمٍ | إِنَّ الْأَبْرَارَ لَفِي نَعِيمٍ |
| اَلْفُجَّارُ فِي جَحِيمٍ | إِنَّ الْفُجَّارَ لَفِي جَحِيمٍ |
| اَلْإِنْسَانُ لِرَبِّهِ لَكَنُودٌ | إِنَّ الْإِنْسَانَ لِرَبِّهِ لَكَنُودٌ |
| رَبُّهُمْ بِهِمْ يَوْمَئِذٍ لَخَبِيرٌ | إِنَّ رَبَّهُمْ بِهِمْ يَوْمَئِذٍ لَخَبِيرٌ |
| اِلٰهُكُمْ وَاحِدٌ | إِنَّ اِلٰهَكُمْ لَوَاحِدٌ |
| أَنْكَرُ الْأَصْوَاتِ لَصَوْتُ الْحَمِيرِ | إِنَّ أَنْكَرَ الْأَصْوَاتِ لَصَوْتُ الْحَمِيرِ |
| رَبِّي سَمِيعُ الدُّعَاءِ | إِنَّ رَبِّي لَسَمِيعُ الدُّعَاءِ |
| هُوَ عَلَى ذٰلِكَ شَهِيدٌ | إِنَّهُ عَلَى ذٰلِكَ لَشَهِيدٌ |
| هُوَ لِحُبِّ الْخَيْرِ لَشَدِيدٌ | إِنَّهُ لِحُبِّ الْخَيْرِ لَشَدِيدٌ |
| أَنْتَ رَسُولُ اللّٰهِ | إِنَّكَ لَرَسُولُ اللّٰهِ |
| أَنْتَ رَسُولُهُ | إِنَّكَ لَرَسُولُهُ |
| هٰذَا فِي الصُّحُفِ الْأُولٰى | إِنَّ هٰذَا لَفِي الصُّحُفِ الْأُولٰى |
| فِي ذٰلِكَ عِبْرَةٌ | إِنَّ فِي ذٰلِكَ لَعِبْرَةً |
| فِي السَّمٰوَاتِ وَالْأَرْضِ آيَاتٌ لِلْمُؤْمِنِينَ | إِنَّ فِي السَّمٰوَاتِ وَالْأَرْضِ لَآيَاتٍ لِلْمُؤْمِنِينَ |

**نوٹ:** حالت نصب اور جر کی ضمائر هُمَا ، هُمْ اور هُنَّ کو بھی تبدیلی کے ساتھ پڑھا اور لکھا جاتا ہے۔ ان کا اصول ہے کہ اگر ان ضمائر سے پہلے
زیر آجاۓ یا
یاۓ ساکن آجاۓ
تو انھیں بالترتیب هِمَا ، هِمْ اور هِنَّ لکھا اور پڑھا جاتا ہے مثلاً:

| | | |
| :---: | :---: | :---: |
| بِهِمَا | بِهِمْ | بِهِنَّ |
| عَلَيْهِمَا | عَلَيْهِمْ | عَلَيْهِنَّ |

## واحد متکلم کی ضمیر یعنی "ی":

واحد متکلم کی ضمیر کو یاء متکلم کہا جاتا ہے اس ضمیر کے متعلق بھی چند اہم باتیں نوٹ کرنے والی ہیں۔
☆ یاء متکلم اپنے ماقبل زیر demand کرتی ہے اسم اس کی یہ demand پوری کرتا ہے لہذا جب بھی مرکب اضافی میں یاء متکلم استعمال ہو تو مرکب اضافی تینوں اعرابی حالتوں میں ایک ہی شکل اختیار کیے ہوتا ہے۔

| | | | | |
| :---: | :---: | :---: | :---: | :---: |
| حالت رفع | كِتَابُ | + | ی | = كِتَابِیْ |
| حالت نصب | كِتَابَ | + | ی | = كِتَابِیْ |
| حالت جر | كِتَابِ | + | ی | = كِتَابِیْ |

☆ یاء متکلم کی طرف جب مثنی اور جمع سالم (مذکر) مضاف ہو کر آتے ہیں تو یاء متکلم پر زبر آتی ہے، مثلاً:

| | | | | | | | | |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| حالت رفع | كِتَابَا | + | ی | = كِتَابَایْ | بَنُوْ | + | ی | = بَنِيَّ |
| حالت نصب اور جر | كِتَابَيْ | + | ی | = كِتَابَيْ | بَنِيْ | + | ی | = بَنِيَّ |

☆ یاء متکلم سے پہلے اگر الف آجاۓ تو بھی یاء متکلم پر زبر آتی ہے مثلاً: عَصَاىَ (میری لاٹھی)
☆ یاء متکلم کو آگے ملائیں تو بھی اس پر زبر آتی ہے مثلاً: رَبِّيَ اللهُ (میرا رب اللہ ہے)
☆ اور زبر دیے بغیر بھی آگے ملا کر پڑھا جا سکتا ہے مثلاً: لَا يَنَالُ عَهْدِي الظَّالِمِينَ

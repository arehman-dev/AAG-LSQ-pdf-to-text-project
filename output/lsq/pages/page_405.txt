| أَنْتَ مِنَ الْخَاطِئِينَ | إِنَّكَ مِنَ الْخَاطِئِينَ |
| أَنْتُمْ جَاهِلُونَ | إِنَّكُمْ جَاهِلُونَ |
| أَنَا مُسْلِمٌ | إِنِّي مُسْلِمٌ |
| نَحْنُ عِبَادُ اللهِ | إِنَّنَا عِبَادُ اللهِ |
| فِي الْجَسَدِ مُضْغَةٌ | إِنَّ فِي الْجَسَدِ مُضْغَةً |
| لِي جَارَانِ | إِنَّ لِي جَارَيْنِ |
| صَلَاتِي وَنُسُكِي وَمَحْيَايَ وَمَمَاتِي لِلَّهِ رَبِّ الْعَالَمِينَ | إِنَّ صَلَاتِي وَنُسُكِي وَمَحْيَايَ وَمَمَاتِي لِلَّهِ رَبِّ الْعَالَمِينَ |
| هَذِهِ تَذْكِرَةٌ | إِنَّ هَذِهِ تَذْكِرَةٌ |
| خَيْرُ الْحَدِيثِ كِتَابُ اللهِ | إِنَّ خَيْرَ الْحَدِيثِ كِتَابُ اللهِ |
| لِكُلِّ أُمَّةٍ فِتْنَةٌ | إِنَّ لِكُلِّ أُمَّةٍ فِتْنَةً |

| علم نفع دینے والا ہے | الْعِلْمُ نَافِعٌ |
| یقیناً علم نفع دینے والا ہے | إِنَّ الْعِلْمَ نَافِعٌ |
| اللہ کی مدد قریب ہے | نَصْرُ اللهِ قَرِيبٌ |
| بیشک اللہ کی مدد قریب ہے | إِنَّ نَصْرَ اللهِ قَرِيبٌ |
| تیرے رب کی پکڑ سخت ہے | بَطْشُ رَبِّكَ شَدِيدٌ |
| یقیناً تیرے رب کی پکڑ سخت ہے | إِنَّ بَطْشَ رَبِّكَ شَدِيدٌ |
| یقیناً قیامت کا زلزلہ بڑی چیز ہے | إِنَّ زَلْزَلَةَ السَّاعَةِ شَيْءٌ عَظِيمٌ |
| بیشک اللہ ہر چیز پر قادر ہے | إِنَّ اللهَ قَدِيرٌ عَلَى كُلِّ شَيْءٍ |
| یقیناً کافر جہنم کی آگ میں داخل ہونے والے ہیں | إِنَّ الْكُفَّارَ دَاخِلُونَ فِي نَارِ جَهَنَّمَ |
| واقعی وہ نیک ہے | إِنَّهُ صَالِحٌ |

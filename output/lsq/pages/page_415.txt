صفحہ ( 199 )

عربی میں ترجمہ کریں۔

| اردو | عربی |
| :--- | :--- |
| استاد کا نیک شاگرد | تِلْمِيذُ الْأُسْتَاذِ الصَّالِحُ |
| محنتی استاد کا شاگرد | تِلْمِيذُ الْأُسْتَاذِ الصَّالِحِ |
| اللہ کی عظیم نعمت | نِعْمَةُ اللَّهِ الْعَظِيمَةُ |
| عظیم اللہ کی نعمت | نِعْمَةُ اللَّهِ الْعَظِيمِ |
| اللہ کی بھڑکائی ہوئی آگ | نَارُ اللَّهِ الْمُوقَدَةُ |
| نیک مومنوں کے دل | قُلُوبُ الْمُؤْمِنِينَ الصَّالِحِينَ |
| محنتی استانی کا نیک شاگرد | تِلْمِيذُ الْأُسْتَاذِ الْمُجْتَهِدِ الصَّالِحُ |

# إِفْعَال

اس باب کے نام کے وزن پر استعمال ہونے والے بہت سے الفاظ ہم اردو زبان میں استعمال کرتے ہیں مثلاً:
اِکرام، اِخراج، اِنکار، اِقرار، اِدغام، اِنفاق، اِنصاف، اِسلام
اِرسال، اِعراض، اِنذار، اِحسان، اِسراف، اِصلاح، اِنعام، اِفہام

**أَفْعَلَ - يُفْعِلُ - إِفْعَالًا**

| ماضی | واحد | مثنیٰ | جمع |
| :--- | :--- | :--- | :--- |
| غائب (3rd Person) | مذکر | أَفْعَلَ | أَفْعَلَا | أَفْعَلُوا |
| | مؤنث | أَفْعَلَتْ | أَفْعَلَتَا | أَفْعَلْنَ |
| حاضر (2nd Person) | مذکر | أَفْعَلْتَ | أَفْعَلْتُمَا | أَفْعَلْتُمْ |
| | مؤنث | أَفْعَلْتِ | أَفْعَلْتُمَا | أَفْعَلْتُنَّ |
| متکلم (1st Person) | مذکر/مؤنث | أَفْعَلْتُ | | أَفْعَلْنَا |

| مضارع | واحد | مثنیٰ | جمع |
| :--- | :--- | :--- | :--- |
| غائب (3rd Person) | مذکر | يُفْعِلُ | يُفْعِلَانِ | يُفْعِلُونَ |
| | مؤنث | تُفْعِلُ | تُفْعِلَانِ | يُفْعِلْنَ |
| حاضر (2nd Person) | مذکر | تُفْعِلُ | تُفْعِلَانِ | تُفْعِلُونَ |
| | مؤنث | تُفْعِلِينَ | تُفْعِلَانِ | تُفْعِلْنَ |
| متکلم (1st Person) | مذکر/مؤنث | أُفْعِلُ | | نُفْعِلُ |

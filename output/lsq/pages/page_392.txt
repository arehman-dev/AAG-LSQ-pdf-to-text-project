## صفحہ نمبر (61)

| | | | |
| :--- | :--- | :--- | :--- |
| ہاشم ایک ڈاکٹر ہے۔ | ہَاشِمٌ طَبِيبٌ | فاطمہ ایک ڈاکٹر ہے۔ | فَاطِمَةُ طَبِيبَةٌ |
| زینب ایک انجینئر ہے | زَيْنَبُ مُهَنْدِسَةٌ | خالدہ ایک طالبہ ہے | خَالِدَةُ طَالِبَةٌ |
| عائشہ محنتی ہے | عَائِشَةُ مُجْتَهِدَةٌ | زاہدہ لمبی ہے | زَاهِدَةُ طَوِيلَةٌ |
| لائبہ چھوٹے قد والی ہے | لَائِبَةُ قَصِيرَةٌ | زمین خوبصورت ہے | نَرْمِينُ جَمِيلَةٌ |
| شاہدہ کھڑی ہوئی ہے۔ | شَاهِدَةٌ قَائِمَةٌ | امامہ بیٹھی ہوئی ہے | أَمَامَةُ جَالِسَةٌ |
| مریم بیمار ہے | مَرْيَمُ مَرِيضَةٌ | | |

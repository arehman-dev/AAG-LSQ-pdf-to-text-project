| اسے مارا جاتا ہے | يُضْرَبُ |
| انھیں رزق دیا جاتا ہے | يُرْزَقُونَ |
| تم (سب) لوٹائے جاؤ گے | تُرْجَعُونَ |
| آج مسجد کا دروازہ کھولا جائے گا | اَلْيَوْمَ يُفْتَحُ بَابُ الْمَسْجِدِ |
| اُس (مؤنث) سے کوئی سفارش قبول نہیں کی جائے گی | لَا تُقْبَلُ / يُقْبَلُ مِنْهَا شَفَاعَةٌ |
| وہ قتل کرتے ہیں اور قتل کیے جاتے ہیں | يَقْتُلُونَ وَيُقْتَلُونَ |
| تم (سب) سے سوال نہیں کیا جائے گا | لَا تُسْأَلُونَ |
| اس پر رحم نہیں کیا جائے گا | لَا يُرْحَمُ |
| مجرم قیامت کے روز اپنے چہروں سے پہچانے جائیں گے | يُعْرَفُ الْمُجْرِمُونَ بِسِيمَاهُمْ يَوْمَ الْقِيَامَةِ |
| یہ کتاب عنقریب پڑھ لی جائے گی | سَيُقْرَأُ هَذَا الْكِتَابُ |

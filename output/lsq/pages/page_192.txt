## اَلْمَمْنُوعُ مِنَ الصَّرْفِ

(غیر منصرف)

ہم جانتے ہیں کہ عربی زبان میں استعمال ہونے والے تقریباً 13% اسماء غیرمنصرف ہوتے ہیں۔ غیر منصرف اسماء پر ایک تو تنوین نہیں آتی اور دوسرے یہ کہ حالتِ جَرّ میں یہ زیر نہیں ہوتے۔ یعنی ان پر حالتِ جَرّ میں کسرہ نہیں آتا۔ جیسے:

| حالتِ جَرّ | حالتِ نصب | حالتِ رفع |
| :---: | :---: | :---: |
| إِبْرَاهِيمَ | إِبْرَاهِيمَ | إِبْرَاهِيمُ |
| أُسَامَةَ | أُسَامَةَ | أُسَامَةُ |
| فَاطِمَةَ | فَاطِمَةَ | فَاطِمَةُ |
| بَاكِسْتَانَ | بَاكِسْتَانَ | بَاكِسْتَانُ |
| عُمَرَ | عُمَرَ | عُمَرُ |
| أَكْبَرَ | أَكْبَرَ | أَكْبَرُ |
| عُمْرَانَ | عُمْرَانَ | عُمْرَانُ |
| وَلَيْمَ | وَلَيْمَ | وَلَيْمُ |
| صَفْرَاءَ | صَفْرَاءَ | صَفْرَاءُ |
| غُرَبَاءَ | غُرَبَاءَ | غُرَبَاءُ |
| مَسَاجِدَ | مَسَاجِدَ | مَسَاجِدُ |

عربی زبان میں استعمال ہونے والے غیرمنصرف اسماء کون سے ہیں؟ یہ ایک دلچسپ موضوع ہے۔ گرامر والوں کے مطابق غیر منصرف وہ اسم ہے جس میں اسبابِ منع صرف میں سے دو سبب پائے جائیں یا ان میں سے ایک ایسا سبب ہو جو دو کے قائم مقام ہو۔

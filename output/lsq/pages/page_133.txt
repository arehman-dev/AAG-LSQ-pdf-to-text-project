# فعل ماضی میں نفی کے معنی پیدا کرنا

فعل ماضی کے شروع میں **مَّا** لگا دینے سے اس میں نفی کے معنی پیدا ہو جاتے ہیں مثلاً:

زید خوش ہوا  
زید خوش نہیں ہوا  
میں نے زید کو نہیں مارا  

فَرِحَ زَيْدٌ  
مَا فَرِحَ زَيْدٌ  
مَا ضَرَبْتُ زَيْدًا  

عربی میں ترجمہ کریں۔

| | |
| :--- | :--- |
| لڑکوں نے اپنا سبق نہیں پڑھا | (قَرَأَ) |
| زید نے تمہاری کتاب نہیں چرائی | (سَرَقَ) |
| میں نے سبق یاد نہیں کیا | (حَفِظَ) |
| زید مسجد سے نہیں لوٹا | (رَجَعَ) |
| یہودیوں نے عیسیٰ کو قتل نہیں کیا | (قَتَلَ) |
| انہوں نے اُس کو قتل نہیں کیا | |
| تم (سب) نے آج قرآن نہیں پڑھا | |
| ان کی تجارت نفع بخش نہ ہوئی | (رَبِحَ) |
| زینب نے فاطمہ کی مدد نہ کی | (نَصَرَ) |
| لڑکے نے پانی نہ پیا | (شَرِبَ) |

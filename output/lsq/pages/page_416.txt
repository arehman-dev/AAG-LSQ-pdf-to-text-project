صفحہ (201)

عربی میں ترجمہ کریں۔

| اردو | عربی |
| :--- | :--- |
| اُس سکول کا لڑکا | وَلَدُ تِلْكَ الْمَدْرَسَةِ |
| سکول کی یہ لڑکی | بِنْتُ هٰذِهِ الْمَدْرَسَةِ |
| اِس گھر کا رب | رَبُّ هٰذَا الْبَيْتِ |
| میری یہ قمیض (قَمِيْصٌ) | قَمِيْصِيْ هٰذَا |
| میرے استاد کی یہ گاڑی (سَيَّارَةٌ) | سَيَّارَةُ أُسْتَاذِيْ هٰذِهِ |
| تمہارا یہ بھائی | أَخُوْكَ هٰذَا |
| لڑکے کی وہ سائیکل (دَرَّاجَةٌ) | دَرَّاجَةُ الْوَلَدِ تِلْكَ |
| نیک معلمہ کا یہ لڑکا | وَلَدُ الْمُعَلِّمَةِ الصَّالِحَةِ هٰذَا |
| میرے بھائی کا وہ گھر | بَيْتُ أَخِيْ ذٰلِكَ |
| شہر کی یہ مساجد | مَسَاجِدُ الْبَلَدِ هٰذِهِ |

لسان القرآن

## جملہ فعلیہ کا اہم ترین قاعدہ

☆ جملہ فعلیہ میں فاعل اگر اسم ظاہر ہو تو فعل ہمیشہ واحد آئے گا چاہے فاعل واحد ہو مثنیٰ ہو یا جمع ہو۔

| اردو | عربی |
| :--- | :--- |
| کسی معلم نے لکھا | كَتَبَ مُعَلِّمٌ |
| (کوئی سے) دو معلموں نے لکھا | كَتَبَ مُعَلِّمَانِ |
| (کچھ) معلموں نے لکھا | كَتَبَ مُعَلِّمُوْنَ |

البتہ جنس کا لحاظ رکھا جائے گا

| اردو | عربی |
| :--- | :--- |
| (کسی) معلمہ نے لکھا | كَتَبَتْ مُعَلِّمَةٌ |
| (کوئی سی) دو معلمات نے لکھا | كَتَبَتْ مُعَلِّمَتَانِ |
| (کچھ) معلمات نے لکھا | كَتَبَتْ مُعَلِّمَاتٌ |

☆ فاعل اگر غیر عاقل (مذکر/مونث) کی جمع مکسر ہو تو فعل مونث آئے گا۔

| اردو | عربی |
| :--- | :--- |
| اونٹ گئے | ذَهَبَتِ الْجِمَالُ |
| اونٹنیاں گئیں | ذَهَبَتِ النُّوقُ |

☆ مندرجہ ذیل صورتوں میں فعل کا مذکر یا مونث دونوں طرح لانا جائز ہے۔

۱۔ فاعل اگر عاقل (مذکر یا مونث) کی جمع مکسر ہو

| اردو | عربی |
| :--- | :--- |
| مرد داخل ہوئے | دَخَلَ الرِّجَالُ یا دَخَلَتِ الرِّجَالُ |
| عورتیں داخل ہوئیں | دَخَلَتِ النِّسَاءُ یا دَخَلَ النِّسَاءُ |

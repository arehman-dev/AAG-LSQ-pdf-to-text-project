صفحہ نمبر (72)

| | | | |
| :--- | :--- | :--- | :--- |
| اَلْمُسْلِمُ صَادِقٌ | هُوَ صَادِقٌ | اَلْمُسْلِمَانِ صَادِقَانِ | هُمَا صَادِقَانِ |
| اَلْمُسْلِمُونَ صَادِقُونَ | هُمْ صَادِقُونَ | اَلطَّالِبَةُ مُجْتَهِدَةٌ | هِيَ مُجْتَهِدَةٌ |
| اَلطَّالِبَتَانِ مُجْتَهِدَتَانِ | هُمَا مُجْتَهِدَتَانِ | اَلطَّالِبَاتُ مُجْتَهِدَاتٌ | هُنَّ مُجْتَهِدَاتٌ |
| اَلْبَابُ مَفْتُوحٌ | هُوَ مَفْتُوحٌ | اَلْبَابَانِ مَفْتُوحَانِ | هُمَا مَفْتُوحَانِ |
| اَلْأَبْوَابُ مَفْتُوحَةٌ | هِيَ مَفْتُوحَةٌ | اَلنَّافِذَةُ مَفْتُوحَةٌ | هِيَ مَفْتُوحَةٌ |
| اَلنَّافِذَتَانِ مَفْتُوحَتَانِ | هُمَا مَفْتُوحَتَانِ | اَلنَّوَافِذُ مَفْتُوحَةٌ | هِيَ مَفْتُوحَةٌ |
| اَلْكُتُبُ مُفِيدَةٌ | هِيَ مُفِيدَةٌ | اَلسُّرُرُ جَدِيدَةٌ | هِيَ جَدِيدَةٌ |

صفحہ نمبر (75)

| | | | |
| :--- | :--- | :--- | :--- |
| نیک آدمی | اَلرَّجُلُ الصَّالِحُ | اچھا لڑکا | اَلْوَلَدُ الْحَسَنُ |
| حکمت والا قرآن | اَلْقُرْآنُ الْحَكِيمُ | سیدھا راستہ | اَلصِّرَاطُ الْمُسْتَقِيمُ |
| (ایک) عادل حکمران | اِمَامٌ عَادِلٌ | (ایک) طویل جنگ | حَرْبٌ طَوِيلَةٌ |
| دو نیک استاد | اَلْأُسْتَاذَانِ الصَّالِحَانِ | دو محنتی استانیاں | اَلْأُسْتَاذَتَانِ الْمُجْتَهِدَتَانِ |
| دو نئی گاڑیاں | اَلسَّيَّارَتَانِ لَجَدِيدَتَانِ | دو پرانی کتابیں | اَلْكِتَابَانِ الْقَدِيمَانِ |
| نیک عورتیں | اَلنِّسَاءُ الصَّالِحَاتُ | لمبے آدمی | اَلرِّجَالُ الطَّوِيلُونَ / الطِّوَالُ |
| (ایک) زرد گائے | بَقَرَةٌ صَفْرَاءُ | (ایک) نیلا رومال | مِنْدِيلٌ أَزْرَقُ |
| کھلی کھڑکیاں (نوافذ) | اَلنَّوَافِذُ الْمَفْتُوحَةُ | بند دروازے (مغلق) | اَلْأَبْوَابُ الْمُغْلَقَةُ |
| خوبصورت گھڑیاں | اَلسَّاعَاتُ الْجَمِيلَةُ | ایسا علم جو نفع دینے والا ہو | عِلْمٌ نَافِعٌ |
| ایسا عمل جو مقبول ہو | عَمَلٌ مُتَقَبَّلٌ | ایسا رزق جو پاک ہو | رِزْقٌ طَيِّبٌ |

① عربی میں ترجمہ کریں:

| اُس کا رسول | اِس کا بندہ |
| :--- | :--- |
| اِس کا مال | ان دونوں کا گھر |
| اِس کے دونوں ہاتھ | اُن سب کے اعمال |
| تمہارادین | تمہارا حال |
| تم دونوں کا رب | تمہاری اولاد |
| ہمارے اعمال | میری قمیض |
| میرا جینا (مَحْيَایَ) | میرا مرنا (مَمَاتِیْ) |
| میرا رب | میری گاڑی |
| ہمارا گھر | ہمارا رب |
| تم سب (مؤنث) کے گھر | تم سب کی مائیں |

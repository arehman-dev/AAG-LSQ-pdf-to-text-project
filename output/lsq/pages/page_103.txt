## مشق

1: مندرجہ ذیل جملوں پر ”إِنَّ“ داخل کر کے ترجمہ کریں۔

| | |
| --- | --- |
| | اَللَّهُ غَفُورٌ |
| | اَلرَّجُلَانِ صَالِحَانِ |
| | اَلْمُعَلِّمُونَ مُجْتَهِدُونَ |
| | اَلْبِنْتَانِ صَادِقَتَانِ |
| | اَلنِّسَاءُ مُؤْمِنَاتٌ |
| | هُوَ صَادِقٌ |
| | هُمْ كَاذِبُونَ |
| | هِيَ مُجْتَهِدَةٌ |
| | أَنْتَ أَمِينٌ |
| | أَنْتَ مِنَ الْخَاطِئِينَ |
| | أَنْتُمْ جَاهِلُونَ |
| | أَنَا مُسْلِمٌ |
| | نَحْنُ عِبَادُ اللَّهِ |
| | فِي الْجَسَدِ مُضْغَةٌ |
| | لِي جَارَانِ |
| | صَلَاتِي وَنُسُكِي وَمَحْيَايَ وَمَمَاتِي لِلَّهِ رَبِّ الْعَالَمِينَ |
| | هَذِهِ تَذْكِرَةٌ |
| | خَيْرُ الْحَدِيثِ كِتَابُ اللَّهِ |
| | لِكُلِّ أُمَّةٍ فِتْنَةٌ |

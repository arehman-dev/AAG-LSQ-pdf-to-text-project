# مضارع مجہول

جس طرح ماضی مجہول کا ایک ہی وزن تھاـــ **فُعِلَ**  
اسی طرح مضارع مجہول کا بھی ایک ہی وزن ہے۔ **يُفْعَلُ**  

يُنْصَرُ سے يُنْصَرُ  
يُقْبَلُ سے يُقْبَلُ  
يُضْرَبُ سے يُضْرَبُ  

فعل مجہول کے بارے میں تفصیل سے گفتگو ہم ماضی مجہول کے سبق میں کر چکے ہیں۔  

## مشق

درج ذیل کا عربی میں ترجمہ کریں۔  

| اردو | عربی |
| :--- | :--- |
| اسے مارا جاتا ہے | |
| انہیں رزق دیا جاتا ہے | |
| تم (سب) لوٹائے جاؤ گے | |
| آج مسجد کا دروازہ کھولا جائے گا | |
| اُس (مؤنث) سے کوئی سفارش قبول نہیں کی جائے گی | |
| وہ قتل کرتے ہیں اور قتل کیے جاتے ہیں | |
| تم (سب) سے سوال نہیں کیا جائے گا | |
| اس پر رحم نہیں کیا جائے گا | |
| مجرم قیامت کے روز اپنے چہروں سے پہچانے جائیں گے | |
| یہ کتاب عنقریب پڑھ لی جائے گی | |

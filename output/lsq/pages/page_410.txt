صفحہ نمبر (133)

| اردو ترجمہ | عربی عبارت |
| :--- | :--- |
| کیا تم (سب مؤنث) نے آج قرآن پڑھا؟ | هَلْ قَرَأْتُنَّ الْقُرْآنَ الْيَوْمَ |
| ہاں ہم نے آج قرآن پڑھا | نَعَمْ قَرَأْنَا الْقُرْآنَ الْيَوْمَ |
| کیا تو (مؤنث) نے اپنا کھانا کھا لیا؟ | هَلْ أَكَلْتِ طَعَامَكِ |
| ہاں میں نے اپنا کھانا کھایا | نَعَمْ أَكَلْتُ طَعَامِي |
| تو نے مجھے کیوں مارا؟ | لِمَ ضَرَبْتَنِي |
| تیرا بھائی کہاں گیا؟ | أَيْنَ ذَهَبَ أَخُوكَ |
| تمہارے ابو لاہور سے کب آئے؟ | مَتَى رَجَعَ أَبُوكَ مِنْ لَاهُورَ |
| اے فاطمہ! تجھے کس نے پیدا کیا؟ | يَا فَاطِمَةُ مَنْ خَلَقَكِ |
| اے لوگو! آسمانوں اور زمین کو کس نے پیدا کیا؟ | يَا أَيُّهَا النَّاسُ! مَنْ خَلَقَ السَّمَوَاتِ وَالْأَرْضَ |
| اے کافرو! تم نے اللہ کا کیوں انکار کیا؟ | يَا أَيُّهَا الْكَافِرُونَ لِمَ كَفَرْتُمْ بِاللَّهِ |

## افتعال کے خصوصی قواعد

باب افتعال میں ”ف“ کلمہ اگر (د، ذ، ز) میں سے کوئی حرف ہو تو باب افتعال کی ”ت“ کو ”د“ میں تبدیل کر دیتے ہیں۔

”ف“ کلمہ اگر ”د“ ہے تو ”ت“ سے تبدیل شدہ ”د“ میں کوئی تبدیلی نہ ہوگی۔

| | | | |
| :--- | :--- | :--- | :--- |
| د خ ل | اِدْتَخَلَ | اِدْدَخَلَ | اِدَّخَلَ |
| | يَدْتَخِلُ | يَدْدَخِلُ | يَدَّخِلُ |

”ف“ کلمہ اگر ”ذ“ یا ”ز“ ہے تو ”ت“ سے تبدیل شدہ ”د“ کے مختلف احوال ہیں۔

”ز“ کی صورت میں ”د“ اپنی حالت میں باقی رہے گی یا ”د“ کو ”ف“ کلمہ کے ہم جنس سے بدل دیا جائے گا مثلاً:

| | | | | |
| :--- | :--- | :--- | :--- | :--- |
| ز ج ر | اِزْتَجَرَ | اِزْدَجَرَ | یا | اِزَّجَرَ |
| | يَرْزَتَجِرُ | يَرْزَدَجِرُ | یا | يَزَّجِرُ |

”ذ“ کی صورت میں ”د“ اپنی حالت میں باقی رہے گی یا ”د“ کو ”ف“ کلمہ کے ہم جنس سے بدل دیا جائے گا یا ”ف“ کلمہ کو ”د“ کے ہم جنس سے بدل دیں گے مثلاً:

| | | | | | | |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| ذ ك ر | اِذْتَكَرَ | اِذْدَكَرَ | یا | اِذَّكَرَ | یا | اِدَّكَرَ |
| | يَدْتَكِرُ | يَدْدَكِرُ | یا | يَذَّكِرُ | یا | يَدَّكِرُ |

باب افتعال کا ”ف“ کلمہ اگر (ص، ض، ط، ظ) میں سے کوئی حرف ہو تو باب افتعال کی ”ت“ تبدیل ہو کر ”ط“ بن جاتی ہے۔ پھر اُس بدلے ہوئے ”ط“ کو ”ف“ کلمہ کے ہم جنس سے بدلنا جائز ہے مثلاً:

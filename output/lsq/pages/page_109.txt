## حروفِ نداء

نداء کے معنی ہیں "بلانا یا پکارنا"، ہر زبان میں کسی کو پکارنے کے لیے کچھ الفاظ مخصوص ہوتے ہیں مثلاً اردو میں "اے لڑکے"، اور "ارے بھائی"، کسی کو پکارنے کے لیے جو الفاظ استعمال کیے جاتے ہیں انھیں **حروفِ نِداء** کہتے ہیں اور جس کو پکارا جائے وہ **مُنَادَى** کہلاتا ہے جیسے "اے لڑکے" میں "اے" حرفِ نِداء ہے اور "لڑکا" مُنَادَى۔

عربی میں پکارنے کے لیے زیادہ تر حرف "يَا" استعمال ہوتا ہے۔

حرفِ نِداء "يَا" کے استعمال کی مختلف صورتیں:

1: مُنَادَى اگر مفرد معرفہ یا نکرہ معین ہو جائے جیسے: **زَيْدُ**، **وَلَدُ**، **نَارُ**، **مَرْيَمُ**، **إِبْرَاهِيمُ**، **مُوسَى** تو جن اسماء پر تنوین آتی ہے ان کی تنوین ختم ہو جاتی ہے۔ ایسے منادی کو مبنی بر رفع کہتے ہیں۔

| | | | | |
| :---: | :---: | :---: | :---: | :---: |
| (اے زید) | **يَا زَيْدُ** | = | **زَيْدُ** | + | **يَا** |
| (اے آگ) | **يَا نَارُ** | = | **نَارُ** | + | **يَا** |
| (اے مریم) | **يَا مَرْيَمُ** | = | **مَرْيَمُ** | + | **يَا** |
| (اے ابراہیم) | **يَا إِبْرَاهِيمُ** | = | **إِبْرَاهِيمُ** | + | **يَا** |
| (اے موسیٰ) | **يَا مُوسَى** | = | **مُوسَى** | + | **يَا** |

2: مُنَادَى اگر معرف باللام ہو تو مذکر کے لیے حرفِ نِداء اور منادی کے درمیان **اُيُّهَا** اور مؤنث کے لیے **اَيَّتُهَا** کا اضافہ کرتے ہیں۔

| | | | | |
| :---: | :---: | :---: | :---: | :---: |
| **يَا أَيَّتُهَا الْبِنْتُ** | **يَا** + **الْبِنْتُ** | | **يَا أَيُّهَا الرَّجُلُ** | **يَا** + **الرَّجُلُ** |
| **يَا أَيَّتُهَا الطِّفْلَةُ** | **يَا** + **الطِّفْلَةُ** | | **يَا أَيُّهَا النَّبِيُّ** | **يَا** + **النَّبِيُّ** |
| **يَا أَيَّتُهَا النَّفْسُ الْمُطْمَئِنَّةُ** | **يَا** + **النَّفْسُ الْمُطْمَئِنَّةُ** | | **يَا أَيُّهَا الْإِنْسَانُ** | **يَا** + **الْإِنْسَانُ** |

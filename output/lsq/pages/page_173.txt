## مشق

درج ذیل فعلیہ جملوں کو اسمیہ جملوں میں تبدیل کریں۔

| | |
| --- | --- |
| | جَلَسَ الْوَلَدَانِ أَمَامَ الْمُعَلِّمِ |
| | نَصَرَ الْمُسْلِمُونَ إِخْوَانَهُمْ |
| | شَرِبَ الْأَوْلَادُ اللَّبَنَ |
| | أَكَلَ الْمُسَافِرُونَ الطَّعَامَ |
| | كَتَبْتُ رِسَالَةً إِلَى أَخِي |
| | أَفَعَلْتَ هَذَا بِالْإِهْتِنَاءِ يَا إِبْرَاهِيمُ؟ |
| | سَمِعَ النَّاسُ كَلَامَ الْخَطِيبِ |
| | دَخَلَ الْوَلَدَانِ الصَّالِحَانِ فِي الْمَسْجِدِ |
| | خَرَجَ فَاطِمَةُ وَ زَيْنَبُ وَ حَامِدٌ مِنَ الْبَيْتِ |
| | رَجَعَتِ الْبَنَاتُ مِنَ الْمَدْرَسَةِ |
| | طَلَبَ الْمُدِيرُ الطُّلَّابَ |
| | دَخَلَ السَّارِقَانِ فِي الْبَيْتِ |
| | خُلِقَ الْإِنْسَانُ مِنْ طِينٍ |
| | نَصَرَ الْمُسْلِمُونَ |
| | طَلَبَ الطَّالِبُ |
| | دَخَلَ فِي الْبَيْتِ |
| | خَرَجُوا مِنَ الْمَسْجِدِ |
| | ذَهَبَتْ إِلَى أُمِّهَا |
| | فَتَحْتُ الْبَابَ |
| | شَرِبْنَا الْمَاءَ |

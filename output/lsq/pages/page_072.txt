## مشق

درج ذیل الفاظ کو دیئے گئے چارٹ کے مطابق ضمائر کے ساتھ استعمال کریں۔

صَادِقٌ صَالِحٌ قَائِمٌ جَالِسٌ بَاكِسْتَانِيٌّ

| | | |
| :---: | :---: | :---: |
| هُمْ مُسْلِمُونَ | هُمَا مُسْلِمَانِ | هُوَ مُسْلِمٌ |
| هُنَّ مُسْلِمَاتٌ | هُمَا مُسْلِمَتَانِ | هِيَ مُسْلِمَةٌ |
| أَنْتُمْ مُسْلِمُونَ | أَنْتُمَا مُسْلِمَانِ | أَنْتَ مُسْلِمٌ |
| أَنْتُنَّ مُسْلِمَاتٌ | أَنْتُمَا مُسْلِمَتَانِ | أَنْتِ مُسْلِمَةٌ |
| نَحْنُ مُسْلِمُونَ | نَحْنُ مُسْلِمَانِ | أَنَا مُسْلِمٌ |
| نَحْنُ مُسْلِمَاتٌ | نَحْنُ مُسْلِمَتَانِ | أَنَا مُسْلِمَةٌ |
| | | |
| | | |

نوٹ: غیر عاقل کی جمع کے لیے ضمیر واحد مؤنث استعمال ہوتی ہے۔
